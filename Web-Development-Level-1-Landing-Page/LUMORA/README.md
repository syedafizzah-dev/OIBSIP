# LUMORA — Modern Living

A clean, responsive landing page created for **LUMORA**, a fictional modern-living brand.

This project was developed as part of the **Oasis Infobyte Web Development & Designing Internship — Level 1, Task 1: Landing Page**.

## 📌 Project Overview

LUMORA is a fictional brand focused on thoughtful, simple, and timeless design for modern living.

The landing page presents the brand through a visually clean layout with a hero section, collection/features section, brand philosophy section, call-to-action section, and footer.

## ✨ Features

* Sticky navigation bar
* Responsive navigation links
* Hero section with headline and call-to-action button
* Collection/features section
* About/brand philosophy section
* Call-to-action section
* Footer with contact and social placeholders
* Smooth scrolling navigation
* Responsive design for desktop, tablet, and mobile screens
* Consistent colour palette and typography
* Clean spacing and modern layout
* No JavaScript required

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Google Fonts**
* **CSS Media Queries**

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the `LUMORA` project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. The landing page will open in your web browser.

Alternatively, `index.html` can be opened directly in a web browser.

## 📱 Responsive Design

The landing page has been designed to work across different screen sizes, including:

* Desktop
* Tablet
* Mobile

CSS media queries are used to adjust layouts, typography, spacing, and grids for smaller screens.

## 🎨 Design Concept

The design uses a minimal and modern visual style with:

* Neutral background tones
* Sage-inspired accents
* Serif headings
* Clean sans-serif body text
* Spacious layouts
* Simple hover effects

The overall design aims to communicate simplicity, comfort, and intentional living.
